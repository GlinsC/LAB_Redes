# Laboratório de Redes

## Sobre o projeto

Este repositório reúne as atividades práticas realizadas na disciplina de **Laboratório de Redes**, utilizando o **Ubuntu Server 26.04 LTS** em uma máquina virtual criada no **Oracle VM VirtualBox**.

Durante as três práticas, foram trabalhados conceitos básicos de administração de servidores Linux, desde a instalação do sistema até o controle de usuários, grupos, diretórios e permissões.

## O que foi realizado

### Aula 01 – Virtualização e Ubuntu Server

* Criação de uma máquina virtual no VirtualBox.
* Instalação do Ubuntu Server 26.04 LTS.
* Configuração de rede.
* Criação do usuário administrador.
* Configuração do particionamento utilizando LVM.
* Instalação do OpenSSH.
* Atualização dos pacotes do sistema.

### Aula 02 – Usuários, Grupos e Permissões

* Criação de usuários no Linux.
* Criação e organização de grupos.
* Criação de diretórios compartilhados.
* Alteração de proprietário e grupo com `chown` e `chgrp`.
* Configuração de permissões utilizando `chmod`.
* Criação e proteção de arquivos.
* Testes de acesso com diferentes usuários.

### Aula 03 – Diretórios e Permissões Avançadas

* Conhecimento da estrutura de diretórios do Linux (FHS).
* Navegação por diretórios como `/etc`, `/var`, `/srv` e `/home`.
* Criação de estruturas de pastas com `mkdir -p`.
* Criação de grupos para diferentes departamentos.
* Separação de acessos entre equipes.
* Configuração de permissões `770` e `660`.
* Testes de acesso e bloqueio entre usuários.

## O que aprendi

Com essas práticas, pude entender melhor como funciona um servidor Linux e como realizar tarefas básicas de administração.

Aprendi a:

* Criar e configurar uma máquina virtual.
* Instalar e configurar um servidor Ubuntu.
* Trabalhar com usuários e grupos.
* Controlar quem pode acessar arquivos e pastas.
* Entender a função dos principais diretórios do Linux.
* Utilizar comandos básicos de administração.
* Configurar permissões para proteger informações.
* Identificar quando um usuário possui ou não acesso a determinado recurso.
* Utilizar o terminal para administrar o servidor.

## Conclusão

As atividades ajudaram a entender, na prática, como um servidor Linux pode ser configurado e organizado. Também foi possível perceber a importância dos usuários, grupos e permissões para manter os arquivos e informações do servidor protegidos e organizados.
